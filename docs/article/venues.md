## Recommendation

1. TMLR is the best first option. It accepts papers at any time, so the team can start the submission in the semester. It judges careful work, and it accepts negative results.
2. Keep the main text to 12 pages or fewer. This keeps the normal review time of about 9 weeks.
3. The second option is a workshop at ICLR 2027, AAAI-27 or CVPR 2027. Most of these workshops publish the call after 2026-11-29 (ICLR) or after 2026-12-22 (CVPR). The authors must check the lists then.
4. The third option is IJCNN 2027, deadline 2027-01-31. Its 6-page limit matches the paper size. Use 2027-01-15 as the safe date.
5. A good local option is PP-RAI 2027 (extended abstract, 2-4 pages) and the xAI 2027 late-breaking track. Both calls are not published, so the dates are estimates.
6. Do not send the same text to two archival venues at the same time. TMLR and CVPR forbid parallel submission of the same work.
7. Post the paper to arXiv when it is ready. arXiv does not count as a duplicate for TMLR. A new arXiv user needs an endorsement for each new category. Ask an established arXiv author, for example the supervisor, to endorse the team.

## Note on arXiv

- A new user needs an endorsement before the first submission, and again for each new category (for example cs.CV and cs.LG).
- An endorser is an established author in the same area. The endorser confirms the topic fit, not the quality.
- A TMLR paper may be on arXiv at any time. The TMLR submission itself must stay anonymous.
